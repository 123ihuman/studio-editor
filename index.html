WebM → MP4

Browsers export WebM (VP9/Opus). Three ways to get MP4:
1. Drop the WebM on cloudconvert.com (free, 25 files/day).
2. Local: ffmpeg -i in.webm -c:v libx264 -crf 18 out.mp4 (fastest, lossless-ish).
3. HandBrake GUI — choose "Fast 1080p30" preset.
Chrome will support native MP4 recording in 2026; until then, conversion is one extra step.

❓ Setup Guide — from zero

Everything below is FREE. No credit card required for any of them.

1. Get a Groq key (for AI scripts)

  1. Go to console.groq.com
  2. Click Sign in → use Google / GitHub
  3. Left menu → API Keys → Create API Key
  4. Name it studio-x → copy the key (starts with gsk_...)
  5. Paste it in Script AI panel → API key field
  6. Free tier: 1,000 requests/day, forever

2. Get a Pexels key (for B-Roll footage)

  1. Go to pexels.com/api
  2. Click Get Started → sign up with email
  3. Verify email → log in → Your API Key
  4. Copy the key (long string of letters/numbers)
  5. Paste it in B-Roll panel → API key field
  6. Free: 200 requests/hour, no card

3. (Optional) Pixabay key

  1. Go to pixabay.com/api/docs/
  2. Sign up → check your email → the key is shown on the docs page
  3. Free: unlimited requests (but 100/min rate limit)

4. Install Node.js (to run proxies)

  1. Go to nodejs.org → download LTS version
  2. Install with default options
  3. Open Terminal (Mac) or Command Prompt (Windows)
  4. Type node -v → should print v20.x.x

5. Run the proxies (one-time)

Put these files next to index.html:
• proxy.js (Part 4/6)
• proxy-free.js (Part 9)
• proxy-broll.js (Part 10)

Then in terminal: 
node proxy.js        # port 8787
node proxy-free.js   # port 8788
node proxy-broll.js  # port 8789
Keep these terminals open while using the app. On the panels, the Proxy URL field should say http://localhost:8787 etc.

6. Host the app (for camera + recording to work)

  1. Create a free account at github.com
  2. New repository → name it studio-x → Public
  3. Upload index.html, manifest.json, sw.js
  4. Settings → Pages → Source: main branch, / (root) → Save
  5. Wait 1 minute. Your app is at https://yourname.github.io/studio-x/
  6. Open it in Chrome. Camera, recording, PWA install all work now.

7. First-run checklist

  • ☐ Hosted on HTTPS (GitHub Pages or Netlify)
  • ☐ Proxies running (node proxy.js etc.)
  • ☐ Groq key pasted in Script AI
  • ☐ Pexels key pasted in B-Roll
  • ☐ Test: Script AI → generate → B-Roll → fetch → Full Pipeline → run

8. Common problems

"Camera blocked" → you must be on HTTPS, not file://. Host on GitHub Pages.

"CORS error" → proxies not running, or you're on file://.

"Face Mesh not ready" → wait 3–5 seconds after enabling. Model downloads once.

"Speech not working" → only works in Chrome/Edge, not Firefox/Safari.

"ffmpeg too slow" → expected; non-realtime export is 5–15 fps rendering. Use a shorter clip range.

"Groq 429" → you hit the daily 1,000 limit. Wait, or use Gemini as fallback.
